# 🛹 Skate 3 Recomp Mods 🎮

[🇦🇷 Español](README.md) · [🇬🇧 English](README.en.md) · [🇧🇷 Português](README.pt.md) · [🇫🇷 Français](README.fr.md) · [🇮🇹 Italiano](README.it.md) · [🇩🇪 Deutsch](README.de.md) · [🇨🇳 中文](README.zh.md) · **🇯🇵 日本語**

[skate3recomp](https://github.com/mchughalex/skate3recomp) 用の**モジュール式** Mod パックです。全部まとめてダウンロードして、使いたいものだけをオンにできます。各モジュールは **Modder**（Skate 3 の雰囲気で、専用ラジオ付きのウィンドウ）からオン・オフでき、すべて元に戻せます。

> 🧩 **[skate3recomp](https://github.com/mchughalex/skate3recomp) v2.0.2 と、あなた自身の Skate 3 が必要です。** これは Modder だけで、ゲーム本体や recomp は含まれていません。

> ⚡ **16.6 秒から約 7 秒へ:** *セーブに直行* を使うと、ゲーム内パッチのおかげで **DROP IN** を押してから約 7 秒で自分のセーブデータで滑り出せます。

## 📦 インストール（Windows）

1. ⬇️ [Releases](../../releases) から `Skate3-Mods.zip` をダウンロードし、好きな場所に展開します（ダウンロードフォルダでも OK）。
2. 🖱️ `Skate3-Mods.exe` を開きます。skate3recomp フォルダを自動で探し、そこに自分をコピーして場所を記憶します。見つからない場合は自分で選べます。
3. ✅ 使いたいものをオンにします。
4. 🛹 **DROP IN**、ショートカット「Skate 3 (directo)」/「Skate 3 (normal)」、または `Jugar Skate 3 (mods).bat` からプレイします。セッション中のヘルパーはこの方法で起動したときだけ動きます。アイコン、グラフィック、言語は `skate3.exe` から直接起動しても有効です。

> 🪟 Modder は WebView2 を使います（Windows 10 と 11 には標準で入っています）。もし無い場合はコンソールメニューが開きます（`Skate3-Mods.exe menu` でも開けます）。

> ⚠️ ゲームを少なくとも一度インストールしておく必要があります（*Select ISO* ボタン）。アイコンやプリセットを変える前にゲームを閉じてください。

> 🛡️ SmartScreen が出たら：「詳細情報」➡️「実行」（.exe は署名されていません）。

## 🎮 ボタンアイコン

| 🟢 Xbox | 🔵 PlayStation |
|---|---|
| Ⓐ Ⓑ Ⓧ Ⓨ | ✖️ ⭕ 🟪 🔺 |
| LB / RB / LT / RT | L1 / R1 / L2 / R2 |
| LS / RS（押し込み） | L3 / R3 |
| Back / Start | PS3: Select / Start · PS4: Share / Options · PS5: Create / Options |

ほかにも **Switch**（Switch 1 と 2、Pro コントローラー、Joy-Con）、**Xbox Series**（ビュー / メニュー）、**GameSir**（Nova Lite、T4、G7 とほとんどの PC コントローラー）、**Steam Deck** に対応。見やすさ重視のセットとして、**白黒**（白地に黒の PlayStation 記号）と**色覚サポート**（Okabe-Ito 配色の Xbox 文字、赤と緑の組み合わせなし）があり、ゲーム内での見え方もプレビューできます。Switch のアイコンはボタンの位置基準です。Steam で「Nintendo のボタン配置を使用」をオンにしていると、A と B が入れ替わります。

アイコンは `game/data/big/fedynamic.big` ➡️ `buttons.rx2` にあります。Mod はオリジナル（`fedynamic.big.xbox-original`）を保存し、「Xbox (original)」で 1 バイト単位まで元どおりに戻します。➕ 十字キーはそのままで、トリックガイドのスティックの絵は「RS」のままです（別のテクスチャのため）。

## 🖼️ プリセット、視野角、ウルトラワイド

値は `skate3.toml` に書き込まれます（ゲームの *Settings* メニューと同じファイルなので、その後もゲーム内で調整を続けられます）。初回に元の `skate3.toml` を `skate3.toml.mods-original` として保存し、「前の設定に戻す」で復元します。

**ウルトラ軽量** は影、SSAO、ブルーム、太陽光線、霧、MSAA をオフにし、描画距離を短くします。かなり非力な PC 向けです。**画面** は `vsync`、`fullscreen`、`monitor`（0 = 自動、1 = 1 枚目の画面、2 = 2 枚目…）を書き込みます。

## ⌨️ キーボードとマウス

recomp の `mnk_mode` を有効にします。マウスでカメラ（右スティック）を動かし、パッドの各ボタンはキーに割り当てられます。**操作** タブでボタンをタップし、割り当てたいキーかクリックを押してください（ほかのボタンが使っていたキーなら入れ替わります）。「デフォルトのキーに戻す」で recomp の初期設定に戻ります。

## ⏩ セーブに直行

recomp 自体の起動自動化機能（`skate3_demo_path` と `skate3_demo_path_signed_in`。プロフィールとセーブデータはそのまま）を使います。イントロをスキップし、言語選択画面、Press Start、起動時のお知らせを通過して、滑り始めた瞬間に操作を返します。その間、黒いロード画面（あなたのボタンスタイルで表示されるヒントと、ロード時間を学習するバー付き）がゲームを隠し、プレイできるようになるとすぐ消えます。それまでゲームはミュートされます。選んだ言語は、このオプションがオンの間、`miscboot.big` 内の英語の場所に入ります。

### 🧩 ダイレクトロードパッチ

オプションがオンのとき、Modder は `skate3.exe` の隣に `xinput9_1_0.dll` を置きます。recomp は起動時にこれを読み込み（コントローラー入力は Windows の xinput に渡すので、操作はこれまでどおり）、**`skate3.exe` が v2.0.2 の場合だけ**（各パッチは exe の関数テーブルから探し、1 バイト単位で検証します）、ゲーム内部から起動を高速化します。

- 🚫 **EA ロゴ** を約 4.7 秒ではなく 0.03 秒で終了。
- 🏎️ ロード中は **FPS 上限なし**（ゲームに入ると元の値に戻ります）。
- ⏱️ **Press Start** の最低待ち時間をなくし、START を即座に入力。
- 😴 **ロードスレッドが居眠りしない:** 各ループの間の 1 ms のスリープをやめます。
- 💓 ロードの短いステップでは **ゲームのティックを 4 ms** に（16.7 ms ではなく）。
- 🖤 **フェードは 1 フレーム**、ゲームに入るまで GPU を高優先度に。
- 📜 `skate3.exe` の隣に **`skate3-direct.log`**：各ステップにかかった時間（**ロード** タブから開けます）。

ほかのバージョンの recomp では何もしません。オプションをオフにするかアンインストールすると削除されます。自分たちのものではない `xinput9_1_0.dll` が既にあった場合は触りません。各機能は環境変数でオフにできます（`SKATE3_DIRECT=0` で全体をオフ）。詳細とコードは [`dll/`](dll/) にあります。

|---|---|---|
| ⏩ ダイレクトロード全体 | 約 16.6 秒 | **約 7 秒** |

## ⚡ ロード

- 🛡️ **Windows Defender:** ゲームフォルダを除外リストに追加し（管理者の許可を一度だけ求めます）、ロード時に毎回ファイルをスキャンしないようにします。
- 🌅 **PC 起動時にプリロード:** Windows の起動時に、ウィンドウを出さずにバックグラウンドで exe、DLL、シェーダーキャッシュ、ゲームファイルを読み込むので、その日最初のロードも速くなります。
- 💽 **SSD:** ゲームがハードディスクにあって SSD がある場合、`X:\Skate3Recomp` にコピーしてサイズを検証し、ショートカット、Steam、プリロードの設定を付け替えます。古いフォルダは指示したときだけ削除します。
- 📊 **履歴:** 直近 20 回のロードを 10 秒と比べて表示し、それぞれ何に時間がかかったかもわかります。前回の時間は **DROP IN** の横に表示されます。
- 📜 **ロードのログ:** ボタン一つで、`skate3-direct.log` を選択した状態でゲームフォルダを開きます。

## 🌐 Español ARG

ゲームの言語選択画面で「Nederlands」が **「Español ARG」** に変わります。ゲームのスペイン語テキストを、ルールに沿ってアルゼンチン（ラプラタ地方）のスペイン語に書き換えたものです。動詞をボセオ（vos の活用）に変え、言い回しも現地のものに置き換えます。たとえば "¿Quieres jugar? Puedes..." ➡️ "¿Querés jugar? Podés..."、"Haz un kickflip y presiona Ⓐ" ➡️ "Hacé un kickflip y presioná Ⓐ"、"colega" ➡️ "loco"、"coches" ➡️ "autos"、"piscina" ➡️ "pileta"、"mola" ➡️ "garpa" といった具合です（約 2,700 件）。元のスペイン語はそのまま残ります。ルールは [`go/rioplatense.txt`](go/rioplatense.txt) にあり、おかしな箇所を見つけたらそこで直せます。

変更するのは `miscboot.big` だけです（`miscboot.big.original` として保存）。オフにするとオランダ語が 1 バイト単位まで元どおりに戻ります。

## 🛹 セッション中のヘルパー

プレイ中はバックグラウンドで動き、ゲームを閉じると一緒に終了します。各機能は **セッション** タブでオン・オフできます。

- ⌨️ **Alt+F4** でウィンドウの × と同じようにゲームを閉じます。
- 🔁 **Ctrl+Alt+R** でゲームが固まったときに閉じて再起動します。
- ⚡ ゲームのプロセスを **高優先度** に。
- ☀️ コントローラーだけで遊んでいても **画面を常にオン**。
- 🖱️ マウスを 3 秒動かさないとゲーム上の **カーソルを非表示**。
- 🪟 ゲームが前面にある間は **Windows キーを無効化**。
- 🗔 **ウィンドウの記憶**：閉じるときにモニター、サイズ、モードを保存。
- 🔕 **おやすみモード**：Windows の通知をオフにし、終了時に元に戻します。

## 🔧 ショップ

- 🖱️ **ショートカット:** デスクトップとスタートメニューに「Skate 3 Mods」「Skate 3 (directo)」「Skate 3 (normal)」を作成。言語ごとのショートカットも作れます。
- 🚂 **Steam:** Skate 3 をライブラリに追加（Big Picture、Steam Input）。
- ⏱️ 日別・週別の **プレイ時間**。
- 🧪 **recomp のバージョン:** 複数のゲームフォルダを、それぞれ別の Mod と設定で管理。
- 🩹 **修復:** `fedynamic.big` と `miscboot.big` をチェックし、壊れたものをバックアップから直します。
- 🔄 **recomp のアップデート後:** ファイルが変わっていたら新しいオリジナルとして扱い、Mod をもう一度適用します。
- 🩺 **診断** と 📣 **問題を報告**（ゲームログの末尾付き）。
- ⬇️ **アップデート:** Releases から新しいバージョンをダウンロードし、自分を置き換えます。
- 💀 **全部アンインストール:** ゲームを Mod 導入前とまったく同じ状態に戻します。

## 📻 Radio Carverton

ブーンバップ、パンク、ロック、エレクトロ、クンビアを Web Audio でリアルタイム生成。曲ごとに違い、Modder を開くたびに新しい曲が始まります（ジャンルか Mix を選べて、シャッフルも可能）。M キーで一時停止。音楽ファイルや著作権のある曲は使っていません。

## ⚙️ 仕組み

- **アイコンとテキスト:** `.big` 内の該当ファイルだけを置き換えます（新しいバージョンを末尾に追加）。ほかの部分には一切触れません。
- **ヘルパー:** `Skate3-Mods.exe play`（DROP IN、ショートカット、Steam、`.bat` が使用。`play direct` と `play normal` で起動方法を選択）がゲームを起動し、ウィンドウのない小さなプロセスを残します。このプロセスはゲームと一緒に終了します。
- **Modder:** `.exe` に埋め込まれた HTML ページ（`go/ui/index.html`）を WebView2 で表示しています。
- 🚫 EA のファイルは一切含まず、配布もしていません。アイコンはオリジナルのアートで、Mod はあなた自身のゲームに適用されます。

### 🐧 Linux / 🍎 macOS

アイコンは Python 3.8 以上で使えます（依存ライブラリなし）。

```sh
python3 src/skate3_ps_buttons.py install ps5 --game /ruta/a/skate3recomp
python3 src/skate3_ps_buttons.py uninstall    --game /ruta/a/skate3recomp
```

## 🛠️ ビルド

```sh
cd go && GOOS=windows GOARCH=amd64 go build -ldflags "-s -w -H windowsgui" -o ../dist/Skate3-Mods.exe .
```

パッチの DLL：`cd dll && sh build.sh`（Linux、clang + lld）。`v*` タグを push すると、GitHub Actions が `.exe` をビルドして zip を Releases にアップロードします。
