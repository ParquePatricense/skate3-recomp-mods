# skate3-recomp-mods
Mod pack modular para skate3recomp con un modeador estilo Skate 3: iconos de PS3/PS4/PS5, Switch, Xbox Series y Steam Deck, presets gráficos, FOV/ultrawide, teclado y mouse, Español ARG y PT-BR, y carga directa a tu partida en ~7 s. Requiere skate3recomp v2.0.2 y tu propia copia de Skate 3.
