为 [skate3recomp](https://github.com/mchughalex/skate3recomp) 打造的**模块化** mod 包：一次全部下载，只开你想要的。每个模块都在 **modder** 里开启或关闭——一个 Skate 3 风格、自带电台的窗口——而且一切都能撤销。

> 🧩 **需要 [skate3recomp](https://github.com/mchughalex/skate3recomp) v2.0.2 和你自己的 Skate 3 副本。** 这里只有 modder：不包含游戏，也不包含 recomp。

## 📦 安装（Windows）

1. ⬇️ 从 [Releases](../../releases) 下载 `Skate3-Mods.zip`，解压到任意位置（“下载”文件夹就行）。
2. 🖱️ 打开 `Skate3-Mods.exe`：它会自动寻找 skate3recomp 文件夹，把自己复制过去并记住位置。找不到的话，会让你手动选择。
3. ✅ 开启你想要的功能。
4. 🛹 用 **DROP IN**、快捷方式“Skate 3 (directo)” / “Skate 3 (normal)”或 `Jugar Skate 3 (mods).bat` 开玩。游戏时助手只有这样启动游戏才会运行；图标、画面和语言即使直接打开 `skate3.exe` 也照样生效。

> 🪟 modder 使用 WebView2，Windows 10 和 11 已自带。如果缺少它，会打开一个控制台菜单（也可以用 `Skate3-Mods.exe menu` 打开）。

> ⚠️ 游戏必须至少安装过一次（*Select ISO* 按钮）。更换图标或预设前请先关闭游戏。

> 🛡️ 如果出现 SmartScreen：“更多信息” ➡️ “仍要运行”（这个 .exe 没有签名）。

| 🟢 Xbox | 🔵 PlayStation |
|---|---|
| Ⓐ Ⓑ Ⓧ Ⓨ | ✖️ ⭕ 🟪 🔺 |
| LB / RB / LT / RT | L1 / R1 / L2 / R2 |
| LS / RS（按下） | L3 / R3 |
| Back / Start | PS3：Select / Start · PS4：Share / Options · PS5：Create / Options |

此外还有：**Switch**（Switch 1 和 2、Pro Controller、Joy-Con）、**Xbox Series**（视图 / 菜单）、**GameSir**（Nova Lite、T4、G7 以及大多数 PC 手柄）和 **Steam Deck**。为了更易辨认：**黑白**（白底黑色的 PlayStation 图形）和**色盲友好**（Xbox 字母使用 Okabe-Ito 配色，没有红绿对比），并可预览它们在游戏中的样子。Switch 图标按位置对应：如果你在 Steam 里开启了“使用 Nintendo 按键布局”，A 和 B 会对调。

图标位于 `game/data/big/fedynamic.big` ➡️ `buttons.rx2`。mod 会备份原文件（`fedynamic.big.xbox-original`），“Xbox (original)”会逐字节还原。➕ 十字键保持不变，Trick Guide 里的摇杆图示仍然写着“RS”（那是另一张贴图）。

## 🖼️ 预设、视野和超宽屏

它们把数值写入 `skate3.toml`（也就是游戏 *Settings* 菜单使用的同一个文件，所以之后还能在那里继续调整）。第一次会把你的 `skate3.toml` 备份为 `skate3.toml.mods-original`；“恢复我之前的设置”会把它还原。

**超轻量**会关闭阴影、SSAO、泛光、太阳光束、雾和 MSAA，并缩短绘制距离：适合配置非常吃紧的电脑。**屏幕**会写入 `vsync`、`fullscreen` 和 `monitor`（0 = 自动，1 = 第一块屏幕，2 = 第二块……）。

## ⌨️ 键盘鼠标

开启 recomp 的 `mnk_mode`：鼠标控制镜头（右摇杆），每个手柄按钮对应一个按键。在**操作**里点一个按钮，再按你想要的键或鼠标键（如果那个键已被别的按钮占用，两者会互换）。“恢复默认按键”会还原 recomp 的默认按键。

## ⏩ 直达存档

使用 recomp 自带的启动自动化（`skate3_demo_path` 配合 `skate3_demo_path_signed_in`，因此会保留你的档案和存档）：跳过片头，自动确认语言界面、Press Start 和启动提示，并在你开始滑的那一刻交还操作。在此期间，一个黑色加载画面（附带用你所选按键风格显示的提示，以及一条会学习你加载时长的进度条）会盖住游戏，等你能玩时立即消失；在那之前游戏保持静音。选项开启期间，你选的语言会替换 `miscboot.big` 里英语的位置。

### 🧩 直达加载补丁

开启该选项后，modder 会在 `skate3.exe` 旁放一个 `xinput9_1_0.dll`。recomp 启动时会加载它（它把手柄交给 Windows 的 xinput，所以操作完全不受影响），并且**仅当 `skate3.exe` 是 v2.0.2 时**（每个补丁都通过 exe 的函数表定位，并逐字节校验），在游戏内部加速启动：

- 🚫 **EA 标志**在 0.03 秒时结束，而不是约 4.7 秒。
- 🏎️ 加载期间**不限 FPS**（进入游戏后恢复你的设定值）。
- ⏱️ **Press Start** 去掉最短等待时间，START 立即生效。
- 😴 **加载器不再打盹：** 加载线程不再在每轮之间休眠 1 毫秒。
- 💓 在加载的短步骤中，**游戏 tick 为 4 毫秒**（而不是 16.7 毫秒）。
- 🖤 **淡入淡出只用一帧**，并且在进入游戏前显卡保持高优先级。
- 📜 `skate3.exe` 旁的 **`skate3-direct.log`**：记录每一步用了多久（可从**加载**打开）。

遇到其他版本的 recomp 时它什么都不改。关闭该选项或卸载时会删除它；如果原本就有一个不属于我们的 `xinput9_1_0.dll`，则不会动它。每个部分都能用环境变量关闭（`SKATE3_DIRECT=0` 会整体关闭）。详情和代码见 [`dll/`](dll/)。

| ⏩ 完整直达加载 | 约 16.6 秒 | **约 7 秒** |

## ⚡ 加载

- 🛡️ **Windows Defender：** 把游戏文件夹加入排除项（只需一次管理员授权），这样加载时就不会扫描每个文件。
- 🌅 **开机时预加载：** Windows 启动时在后台、不弹出任何窗口地读取 exe、DLL、着色器缓存和游戏文件，让当天第一次加载也很快。
- 💽 **SSD：** 如果游戏在机械硬盘上而你有 SSD，它会把游戏复制到 `X:\Skate3Recomp`，校验大小，并重新指向快捷方式、Steam 和预加载；旧文件夹只有在你要求时才会删除。
- 📊 **记录：** 你最近 20 次加载与 10 秒目标的对比，以及每次的时间都花在了哪里；最近一次会显示在 **DROP IN** 旁边。
- 📜 **加载日志：** 一个按钮打开游戏文件夹并选中 `skate3-direct.log`。

## 🌐 Español ARG

在游戏的语言界面里，“Nederlands”会变成 **“Español ARG”**：用规则改写过的游戏西班牙语文本，换成阿根廷（拉普拉塔）口吻。“¿Quieres jugar? Puedes...” ➡️ “¿Querés jugar? Podés...”，“Haz un kickflip y presiona Ⓐ” ➡️ “Hacé un kickflip y presioná Ⓐ”，“colega” ➡️ “loco”，“coches” ➡️ “autos”，“piscina” ➡️ “pileta”，“mola” ➡️ “garpa”，等等（约 2700 条文本）。原版西班牙语保持原样。规则写在 [`go/rioplatense.txt`](go/rioplatense.txt) 里：看到奇怪的地方，就在那里改。

它只改动 `miscboot.big`（备份为 `miscboot.big.original`）；关闭后荷兰语会逐字节恢复。

## 🛹 游戏时助手

在你玩的时候于后台运行，并随游戏一起关闭。每一项都可以在**游戏时**里开启或关闭：

- ⌨️ **Alt+F4** 关闭游戏，跟点窗口的 X 一样。
- 🔁 **Ctrl+Alt+R** 在游戏卡住时关闭并重新打开游戏。
- ⚡ 为游戏进程设置**高优先级**。
- ☀️ **屏幕常亮**，即使你只用手柄玩。
- 🖱️ 鼠标 3 秒不动后，在游戏上方**隐藏光标**。
- 🪟 游戏在前台时**屏蔽 Windows 键**。
- 🗔 **记住窗口**：关闭时保存显示器、大小和模式。
- 🔕 **勿扰模式**：关闭 Windows 通知，退出时再重新开启。

## 📻 Radio Carverton

Boom bap、punk、rock、electro 和 cumbia，全部用 Web Audio 实时生成，每首都不一样，每次打开 modder 都会换一首新歌（可以选曲风或 Mix，以及随机播放）。按 M 键暂停。不使用任何音乐文件，也没有受版权保护的曲目。

## ⚙️ 工作原理

- **图标和文本：** 只替换 `.big` 里对应的文件（把新版本追加到末尾）；其余部分完全不动。
- **助手：** `Skate3-Mods.exe play`（DROP IN、快捷方式、Steam 和 `.bat` 都用它；`play direct` 和 `play normal` 决定启动方式）打开游戏，并留下一个没有窗口的小进程，随游戏一起关闭。
- **modder：** 一个嵌入在 `.exe` 里的 HTML 页面（`go/ui/index.html`），运行在 WebView2 中。
- 🚫 不包含也不分发任何 EA 的文件：图标是原创美术，mod 都是应用在你自己的游戏副本上。
